
# Retinal vessel detection

## The dataset

[Images used for training and evaluation](https://www5.cs.fau.de/research/data/fundus-images/)

## About the project

This project focuses on retinal blood vessel segmentation in fundus images.  
The main goal is to detect and extract blood vessels from retinal photographs using different image analysis techniques.

The repository presents three approaches to vessel segmentation:

- **Classical image processing** — traditional image filtering and segmentation methods (SATO filtr)
- **Machine Learning (ML)** — feature-based machine learning models (Random Forrest)
- **Deep Learning (DL)** — neural network approaches, including U-Net architectures
